# PostgreSQL — схемы и транзакции

Репозиторий воспроизводимых SQL- и Python-сценариев работы с PostgreSQL.

## Возможности

- Изолированные схемы и роли в общем PostgreSQL-окружении.
- Python/Psycopg и параметризованные SQL-запросы.
- Docker Compose и повторяемые сквозные проверки.

## Инженерные акценты

- Практическая работа с данными, транзакциями и правами доступа.
- Воспроизводимость окружения и проверка результата отдельным соединением.
- Небольшие прозрачные реализации без скрывающих SQL абстракций.
